# TravelGo - Travelling Website

A responsive travelling website for exploring destinations and planning trips.

## Features

- User Registration & Login
- Destination Listings
- Search & Filter
- Tour Package Details
- Hotel Booking
- Flight Booking
- Travel Itinerary
- Photo Gallery
- Reviews & Ratings
- Contact Form
- Responsive Design
- Admin Panel

## Technologies Used

- HTML
- CSS
- JavaScript

## Project

TravelGo is a frontend travelling website designed to provide users with an easy way to explore destinations, view tour packages and plan their trips.
